# First scene-conditioned checkpoint — October 30, 2026

Synthetic numerical study built from PR #2 merge
`6f00ac3faa4e34d508b005891e62d9911ead81cf`. Its original rectangular-container
and fixed-bucket results remain in their original directories and definitions.

| Method | Captures / all test layouts | Clean / rim-assisted | Mean opening radial error |
|---|---:|---:|---:|
| Frozen trained ridge policy | 8 / 8 | 5 / 3 | 23.49 mm |
| Fixed action, declared before training | 6 / 8 | 3 / 3 | 70.31 mm |
| Per-scene search, 4 proposals | 8 / 8 | 3 / 5 | 25.63 mm |

All methods use the same eight layout IDs and rollout seeds. All selected actions
passed both-arm endpoint IK; there were no invalid/model-limit test results.
**No native paths or physical trials were checked.** The search row is an
optimizer baseline, not model inference. Eight layouts from a narrow synthetic
distribution are insufficient evidence of reliable or broad generalization.

The ridge model was fitted to 24 training-only teacher labels, selected from
12 proposals per layout. All 24 teachers found a simulated capture. Six disjoint
validation layouts selected alpha 0.01 from 0.01/1/100; all three candidates
captured 6/6, with the declared shaping-score tiebreaker selecting 0.01. The
checkpoint was saved and reloaded before eight test layouts were evaluated and
remained byte-identical afterward. Direct inference is one matrix evaluation,
with no per-layout optimization or adaptation. It outputs board roll/pitch,
board-local U/V, and release gap. Nonzero scene-dependent weights are saved.

Run seed: `20261030`. Checkpoint ID:
`be3cc423190aecef7a2c9b4d456e3b74902ab529f339a616605f5a6d6fb41c4f`.

## Files

- `checkpoint.json`: weights, normalization, source/dependency/asset contracts,
  training and split identities, validation selection, checksum.
- `episodes.json`: all 38 predeclared layouts and independent RNG identities.
- `experiment.json`, `summary.json`: parameters and complete denominators.
- `test-scorecard.json`: all 24 selected method/layout records, actions, endpoint
  IK, entry/bounce/retention outcomes and provenance; no raw sensor observations.
- `preview-scene.json`, `preview.json`: the first predetermined test layout and
  its numerical prediction/trajectory, without selecting a favorable result.
- `SHA256SUMS`: checksums for all seven JSON artifacts.

Full candidate, training-label, validation and test rows are generated by the
reproduction command in [the study guide](../../docs/SCENE_CONDITIONED_STUDY.md)
and retained outside Git. This portable subset contains no credentials, host
calibration, raw captures, queues or machine-specific paths. Historical source
versions are explicitly guarded; use this checkpoint's matching checkout.

The scorer is `sircus-board-bounce-capture-1s-v1`; physics is
`sircus-compliant-board-bucket-impulse-v1`. A board bounce, whole-ball entry and
one uninterrupted simulated second inside are required. Native v2 replay is
still blocked. Board/support/tool dynamics and bucket placement are provisional;
the measured 175 mm bucket height remains unresolved as overall versus interior.

NumPy 2.5.4 and SciPy 1.18.1 match the pinned requirements. The CLI and UI do not
connect to hardware. The existing deployed dashboard/runtime has not been
switched to this scorer or checkpoint.
